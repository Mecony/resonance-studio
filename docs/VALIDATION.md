# v0.1 验证记录

日期：2026-11-05。记录实际执行结果，未实测内容单独列出。

## 自动验证

- 执行环境：Node.js v24.22.1，Linux。
- `npm run check`：应用核心 ES 模块语法检查。
- `npm test`：11 个测试，结果以本次终端输出为准。
- 算法基准：64 点 FFT 与直接 DFT 对照，幅值 0.5 正弦波 RMS 与 0.5/√2 对照。
- 频段基准：110、1000、5000 Hz 测试音，在其对应频段保留主要能量。
- 静音输出全部有限且能量为零；已保存方案的非法数值、主题、版本会被拒绝。

## 浏览器交互验证

在云端 Chrome 中通过真实界面执行：

| 检查 | 结果 |
|---|---|
| 原创示例载入、播放与暂停 | 通过，播放时间与能量显示变化 |
| 花瓣、星环主题和配色切换 | 通过，选中状态和画面变化 |
| 播放进度键盘跳转 | 通过 |
| 1:1 比例及 PNG 下载 | 通过，下载 PNG 实际为 1080×1080 RGBA |
| 方案下载与重新导入 | 通过；音频不匹配时提示重新选择 |
| 本地 WAV 导入 | 通过，3 秒、44.1 kHz 测试音识别成功 |
| 有声短片录制 | 文件成功生成，ffprobe 确认 VP9 视频＋48 kHz Opus 音轨 |

短片音轨经 ffmpeg 解码，RMS 约 −12.8 dBFS，证明非静音。此项检查不能证明感知音画同步。

## 发现的限制

云端录制样本约 3 秒，但只观察到 9 个视频帧，视频首帧时间约 0.21 秒；这不满足流畅视频的验收要求。实时录制仍作为实验功能，不能宣称稳定 30 fps、逐帧同步或生产级视频导出。用户本机前台浏览器需继续验证，或后续实现离线编码。

未完成：Safari/Firefox 实测、手机真机、3 分钟极限文件性能、非法音频 UI 回归、实际 GitHub Actions 运行。不能用已有单元测试替代这些检查。
