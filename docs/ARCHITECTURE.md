# 技术设计

## 数据与时钟

音频导入 → 浏览器解码 → 单声道分析副本传给 Worker → 返回特征数组 → 按播放器的音频时间插值 → Canvas 渲染。

播放保留解码后声道。导入音频在 OfflineAudioContext 中解码为 44.1 kHz；原创示例为 22.05 kHz。暂停时保存偏移，恢复时根据 AudioContext.currentTime 计算起点。画面从音频时间取状态，不通过动画帧累计播放时间。

## 特征定义

- 窗长 N=2048，Hann 窗；步长约 23.22 ms。
- 分析窗围绕每个时间戳居中，首尾补零。因此边界处 RMS 会受到补零影响。
- 原始 RMS 在未加窗样本上计算，`20 log10(RMS)` 作为 dBFS 显示，不代表声压级。
- 低频 [40,250) Hz，中频 [250,2000) Hz，高频 [2000,min(10000,Nyquist)] Hz。
- 频段特征为对应 FFT 模平方和开根号，未做声压校准。
- 三个频段共用其第 95 百分位尺度的最大值，保留频段之间的相对关系；RMS 与突变强度分别归一化。
- 突变强度为相邻帧幅度谱正向差分之和；不是节拍标签。
- 64 个对数频段用于视觉。低频处可能有多个区间共享 FFT 频点，是显示插值，不增加频率分辨率。
- 分析特征预先因果平滑，渲染时线性插值。样本位置、固定种子和参数决定几何状态。

## 渲染

`renderVisual(context,width,height,time,features,settings,metadata)` 不持有上一帧状态。花瓣按分层贝塞尔曲线绘制；星环把频段能量映射为径向长度；几何主题把频谱映射为菱形阵列大小。漂浮粒子的位置由种子、索引、时间的函数决定。

参数调整即时生效。静音时能量响应归零，但播放中的基础时间运动可以继续；“流动速度”为 0 时固定基础漂移，声音响应仍可变化。

## 任务与错误处理

每次载入增加 revision，终止旧 Worker。异步解码结果只有匹配当前 revision 才能提交。导入失败保留之前成功载入的音频和分析数据。播放器 playToken 避免连续点击导致重复音源，暂停可取消尚未完成的播放。

## 保存与导出

JSON 仅保存主题、参数、随机种子、作品标题及音频元数据，不存储音频字节或文件系统路径。导入只读取白名单字段，校验数值范围，使用 textContent/Canvas 绘制标题。

PNG 导出使用画布的实际分辨率。视频将画布 captureStream 的视频轨道和音频 GainNode 的录制目的地轨道合并；音量会影响导出音频。录制期间锁定音频替换、画布比例、重置、跳转和循环切换，防止尺寸或时间轴突变。

当前没有数据库、身份系统、外部 API 或云端音频处理。托管平台自己的访问控制与访问日志不属于应用的音频处理流程。
